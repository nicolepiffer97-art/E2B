# E2B

Sito E2B dedicato alle infrastrutture energetiche e digitali.

Il ramo principale è `main`. GitHub Pages pubblica la cartella principale dello stesso ramo.

## Struttura

- `index.html`: homepage e contenuti.
- `styles.css` e `motion.css`: stile e movimento.
- `app.js` e `motion.js`: interazioni, brief locale e metodo.
- `assets/`: logo, icone e fotografie con relativi crediti.
- `privacy/`: informazioni sul funzionamento dell’anteprima.

La versione include la molecola H₂, la voce MEP nel form e i tratteggi animati nella hero. Il filo luminoso lungo la pagina è rimosso.

Il sito è statico: i file principali sono direttamente modificabili, senza compilazione. Per una verifica locale avviare un server HTTP nella cartella del progetto, ad esempio `python -m http.server 8080`.

Il modulo prepara soltanto un brief nel browser e non invia dati. Le fotografie sono illustrative; i crediti sono in `assets/photo-credits.txt`. Adobe Fonts richiede una connessione.

La presentazione, le fotografie degli appunti e i materiali interni di revisione non fanno parte di questa repository.
